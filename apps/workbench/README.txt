Workbench: the blank app that only hosts Kit and its editor ([KIT],
doc/plan's kit_plan.md). A stone floor to build on, Kit's starter set of
components (builtin/kit/types/) to place, set and link in the editor (F6), and
the voxels to build with. main/main.cpp says how it plays.
