Buildat Server API
==================
What a C++ module sees: the headers under src/interface/ (the server, the
events, modules, voxels, mesh, storage, network, the thread pool) and each
builtin module's api.h. Written against the code 2026-09-21
([CLIENT_API_DOC]); util/api_names.py --check says whether every header
has its section here and regenerates the last section, which lists what
each header declares, by name. The signatures are in the headers; this
file says what each one is for and how the pieces fit.

The client's Lua API is doc/client_api.txt; how the engine is put together
is doc/architecture.txt.


A module
========

A module is a directory: meta.json, <module>.cpp (the server half, compiled
by the server at start through RCC++ and cached under cache/rccpp_build by
the hash of its sources), an optional api.h other modules include to talk
to it, and by convention client_lua/ and client_data/ that builtin/client_lua
and builtin/client_data ship to the client. Modules under builtin/ are the
engine's own; an app's are under apps/<app>/. The engine loads
builtin/loader first, and it reads the rest. Once the load order is
known, the modules whose build is not current are compiled side by side,
the largest first, on at most half the usable cores, each further
compiler only while free memory covers 1 GiB for each running one plus a
1 GiB reserve (BUILDAT_COMPILE_RESERVE_MB raises it), and each beyond a
server's first only with one of the half-the-cores slots all of the
user's servers share (/tmp/buildat-compile-<uid>, or
BUILDAT_COMPILE_SLOTS; none usable, one at a time); loading and init()
stay one at a time, in order. --compile-only compiles and loads them,
then exits (1 naming the module that failed).

<module>.cpp defines a struct deriving from interface::Module and exports
one function:
	extern "C" {
		BUILDAT_EXPORT void* createModule_<name>(interface::Server *server) {
			return (void*)(new Module(server));
		}
	}

Lifecycle, in order:
- the constructor: keep the Server pointer; do not touch other modules;
  throw on a fatal error
- init(): subscribe to events (sub(m_server, "core:start", &Module::on_start))
  and reach other modules
- "core:start": start doing whatever the module actively does
- "core:tick": every server tick, with interface::TickEvent (dtime)
- "core:continue": after a reload, in place of core:start
- "core:unload": the module is unloaded right after the handler; a module
  that keeps state across a reload puts it in tmp_store_data()
- "core:module_loaded" / "core:module_unloaded" / "core:module_modified":
  ModuleLoadedEvent, ModuleUnloadedEvent, ModuleModifiedEvent, by name

An event is named once ([EVENT_SUB_ONCE]): sub(server, name, &Module::handler)
in init() subscribes to it and has the default event() call the handler,
with the event's parameter as the handler's parameter type
(sub(m_server, "core:tick", &Module::on_tick) for
on_tick(const interface::TickEvent&); a handler with no parameter takes
none). A type that is no Event::Private does not compile, an event that
carries another throws, and a second handler for one name throws. A
handler on another object names its type: sub<network::Packet>(m_server,
name, [&](const network::Packet &p){ ... }). The older way still works
(use sub() instead):
server->sub_event(this, Event::t(name)) in init() and an event() of the
module's own listing EVENT_VOIDN("core:start", on_start) and
EVENT_TYPEN("core:tick", on_tick, interface::TickEvent) (event.h); a
module that overrides event() and also calls sub() calls dispatch(type, p)
itself.

Every module runs in a thread of its own, and everything it may reach
officially is thread-safe: another module is reached only through
server->access_module(name, callback), which holds the other's mutex for
the callback -- the api.h convention wraps it as
<module>::access(server, [&](<module>::Interface *i){ ... }). A module's
get_interface() is what access() hands out, checked by check_interface().
The single operations most modules make have one call of their own, an
access() inside each: network::send(server, peer, name, data),
replicate::assign_scene_to_peer(server, scene, peer),
main_context::create_scene(server), main_context::access(server, scene,
[&](magic::Scene *s){ ... }) and voxelworld::get_voxel/set_voxel/
get_sample/set_sample(server, scene, p, ...). Several under one lock are
still an access().
Throwing interface::ModuleAskedToStop from a handler stops the module.
Any other exception from a handler shuts the server down, except on a
network:packet_received/* event: a client's packet the handler cannot read
is dropped and logged, the first ten and then one line every ten seconds
with how many went unsaid.

meta.json: {"engine_api": 2, "cxxflags": "", "ldflags": "",
"dependencies": [{"module": "network"}, {"module": "x", "optional":
true}], "reverse_dependencies": [...], "disable_cpp": false,
"client_main": "init.lua", "client_extensions": ["voxel_light"],
"kind": "app", "web": true}. An app's module must say
engine_api, the engine API it is written for (interface::aitta::
ENGINE_API_MIN...ENGINE_API; 0.7 runs 2); the rest may be left out, and
{"engine_api": 2} is the minimum. A key the loader does not know
(besides those, cxxflags_/ldflags_ with _windows or _linux, and
"comment") is refused at load with the reason, as is an app module named
like one of Buildat's (builtin/). A dependency is loaded first; a reverse
dependency is loaded after this module and says the other may use this
one. disable_cpp is a module with client halves only. client_main names a
script in the module's client_lua/ that the engine runs once on each
client, when its files first arrive (modules in load order).
client_extensions names extensions (<share>/extensions/<name>) the
server serves for the module's client scripts, which run that copy
(buildat.run_script_file("<name>/init.lua")) rather than the client's
bundled one: client_file::serve_extension(). "web": true says the module
keeps to the web API (below).

**The web API** ([WEB_LOCAL_SERVER]): util/build_web_server.sh <app>
builds the server with the app's modules compiled into it, to run in a
browser (doc/architecture.txt, "Running a game in the browser"). It
refuses an app any of whose modules, or the modules they depend on, does
not say "web": true, naming each. There a module is compiled with
BUILDAT_WEB_MODULE, under which interface/tcpsocket.h, http.h, process.h
and select_handler.h are an #error: no sockets, HTTP or processes. Files
are in Emscripten's file system, the app's directories packed into it.
Three builtins have stand-ins there (<name>_web.cpp beside the module's
own), so an app that depends on them builds unchanged: network has one
peer, the page's own client, over postMessage (only the page that made
the worker can send to it); accounts has one player, the first peer to connect, who joins by
name alone (the first join's name, kept in the app's save "_server"), is
is_local() and the admin, and has no passwords, invites, bans, guests or
mail; starport_announce lists nothing and takes no Starport IDs.
client_file watches no files there. The page stops the server by
Module._buildat_server_stop(), as SIGTERM does natively (under node,
SIGTERM and SIGINT call it).

The build is copied to web/local/<app>/, which the buildat server serves
beside the web client. The web client's page opened as /?local=<app>
runs it in a worker and joins it; the server is started with launcher=1
(a local game), its storage (/user) kept in the browser's IndexedDB.
That page and the local server's files are sent cross-origin isolated
(Cross-Origin-Opener-Policy: same-origin, Cross-Origin-Embedder-Policy:
require-corp), which the server's threads need; any other host of web/
has to send the same. The page without ?local is not isolated: an
isolated page's popup has no opener, and the Starport ID's sign-in is
one. util/web_local_check.sh plays hillclimb so from static files.


src/interface, the core
=======================

interface/server.h -- interface::Server, the one object a module holds
- shutdown(status, reason); load_module / unload_module / reload_module,
  has_module, get_loaded_modules, get_module_path, get_modules_path,
  get_builtin_modules_path; set_module_count(n) is the loader telling the
  STATUS lines how many are coming ([START_PROGRESS])
- access_module(name, cb): the only way to another module; always returns
  true (a missing module is an error)
- access_module_optional(name, cb): the same, but false and cb not called
  when the module is not loaded
- sub_event(module, type) (use sub() instead), emit_event(Event) and the
  two templates emit_event(type) / emit_event(type, new PrivateT(...)):
  the private is owned by the event
- tmp_store_data / tmp_restore_data: a named blob that survives a reload
- add_file_path(name, path) / get_file_path(name): the file namespace the
  client mirrors (builtin/client_file serves it); "" when not found
- get_config(): the server's Config (server_config.h); get_app_id(): the
  last component of -m, which namespaces what is kept under the user path
- access_thread_pool(cb): the server's pool (thread_pool.h)
- TickEvent, ModuleModifiedEvent, ModuleLoadedEvent, ModuleUnloadedEvent are
  the privates of the core events above

interface/module.h -- interface::Module, what a module derives from
- init(), event(type, private), get_interface(), check_interface();
  ModuleAskedToStop

interface/module_info.h -- ModuleInfo (name, path, meta), ModuleMeta (what
meta.json holds: cxxflags, ldflags, dependencies, disable_cpp),
ModuleDependency (module, optional)

interface/server_config.h -- interface::ServerConfig, the typedef of
server::Config: get<T>(name) for the keys server/config.cpp sets
(network_port, rccpp_build_path, share_path, user_path, ...).
launch_param(u, key, &refused): one key of the untrusted -u lines, a
directory name's shape (1 to 64 letters, digits, '_', '-') or "", refused
set when the key was there and its value was not ([SHARED_HELPERS]: one
for vanilla, floorplanner and accounts).

interface/event.h -- interface::Event: a Type (an integer from
Event::t("name"), the global registry's) and an optional Private, the
payload struct deriving from Event::Private. EventRegistry names types
(find(name) answers 0 for a name with no type yet, without making one, for
a name off the network); getGlobalEventRegistry(). The EVENT_VOIDN /
EVENT_TYPEN macros (use sub() instead) are the dispatch inside event(),
looking their type up once (a static per site); EVENT_DISPATCH_VOID takes a
Type already looked up. A match returns from event() after its handler ([EVENT_DISPATCH]), so work
for every event goes in a caller of a function that holds only the list;
an event with no payload or the wrong one throws.

interface/magic_event.h, interface/magic_event_handler.h -- Urho3D events on
the server side: MagicEvent carries an Urho3D StringHash and VariantMap as
an interface::Event, MagicEventHandler subscribes an Urho3D object's event
and re-emits it through the server (builtin/main_context uses it for a
scene's events).

interface/thread.h -- interface::Thread (createThread(ThreadedThing*)):
start, request_stop, join, set_name, is_running; ThreadedThing::run() is
the body and on_crash() what runs after a crash in it. ThreadLocalKey; the
caller-thread bookkeeping (set_caller_thread, get_current_thread,
ref_backtraces) is what makes a backtrace across threads readable.

interface/thread_pool.h -- interface::thread_pool::ThreadPool
(createThreadPool()): add_task(Task*), start(n), request_stop, join,
run_post(). A Task has pre() on the caller's thread, thread() on a worker,
post() back on the caller's when it asks (run_post). What the mesher and
the ray casts run on.

interface/mutex.h -- interface::Mutex and MutexScope, the lock everything
above is built on.
interface/semaphore.h -- interface::Semaphore: wait, wait_us, post.

interface/select_handler.h -- SelectHandler: one select() over a set of
fds with a timeout, for a module that waits on sockets and file watches
together (builtin/network's loop).

interface/tcpsocket.h -- interface::TCPSocket (createTCPSocket()): the
wire. connect_fd / bind_fd / listen_fd / accept_fd, send_fd and send_some
(non-blocking, what the send queue drains through), wait_data, the
addresses; probe_connect(host, port) is what the client asks whether a
local server's port answers. local_lan_address() is this machine's IPv4
address on its default route's network; lan_socket / lan_send / lan_recv /
lan_close are the multicast group a LAN game is announced on
(LAN_GROUP 239.255.29.50, LAN_PORT 29599, TTL 1; [LAN_DISCOVERY]).

interface/packet_stream.h -- PacketStream: the framing on a TCP socket --
input(deque, callback) and output(name, data) -- and the two registries a
peer's packet names are numbered by (OutgoingPacketTypeRegistry,
IncomingPacketTypeRegistry); UnknownPacketReceived, which is also what a
packet over the reader's m_max_packet_bytes (256 MB unless the owner sets
less) is.

interface/file_watch.h -- interface::FileWatch (createFileWatch()): inotify
over a set of paths (add), get_fds / report_fd for a select loop, update();
what -R's module reload watches sources with.

interface/fs.h -- interface::fs: list_directory (Node: name, is_directory),
create_directories, get_cwd, get_absolute_path, is_inside_path (the check
every user-given path goes through), path_exists, copy_file, remove_all,
file_size, directory_tree_size, check_file_extension,
strip_file_extension, strip_file_name.

interface/os.h -- interface::os: time_us (monotonic), wall_us (the
calendar; see "Simulated time" in developer_notes.txt), sleep_us,
utc_tm(seconds) (a UTC struct tm), get_current_exe_path,
get_sibling_exe_path (buildat_server beside buildat).

interface/process.h -- interface::process: start(exe, args, ExecOptions) ->
Handle, is_running, request_terminate, terminate, kill_force, shell_exec,
get_environment_variable. A child gets the parent's environment with
opts.env over it; is_running reaps a child that has exited.
open_with_system(target): a link or a folder handed to the desk
(ShellExecute on Windows, open on macOS, xdg-open elsewhere), not waited
for; a target with a quote in it is refused.

interface/debug.h -- backtraces: log_current_backtrace,
get_current_backtrace / get_exception_backtrace (StoredBacktrace),
log_backtrace, log_backtrace_chain (ThreadBacktrace, across the threads
that called into this one), init_signal_handlers(SigConfig) -- the SIGSEGV
and SIGABRT handlers that write "Crash: ..." and the trace to stderr, which
log_set_file() sends into the log file. watchdog_on_freeze(f): what a
30 s freeze runs on the frozen thread besides the log (Linux only).
set_crash_dump_dir(dir, exe) ([WIN_MINIDUMP], Windows; nothing elsewhere):
a crash also writes <dir>/crash-<exe>-<time>.dmp, the newest five kept;
crash_dump_untold(dir), the newest not told about yet, then marked told.
BUILDAT_DEBUG_CRASH=<exe> crashes that exe on purpose, for the test.

interface/compress.h -- compress_zlib / decompress_zlib,
compress_deflate_raw / decompress_deflate_raw, compress_zstd /
decompress_zstd, on strings. A decompressor writes DECOMPRESS_MAX (256 MB)
at most unless the caller passes its own max_out; past it is an exception.
interface/sha1.h, interface/sha256.h -- calculate(data) -> the digest,
hex(digest); sha256's unhex(h) (throws on an odd length or a non-hex
digit) and is_hex(s, len). core/json.h's jstr(v, key, def) and jint(v,
key, def) read an object's string or integer, def for anything else.
interface/bignum.h -- big-endian byte-string integers: add, mul, mod,
sub_mod, mul_mod, mod_exp; random_bytes(n) from the platform's source.
interface/http.h -- http_get(url) -> body, http_post(url, body,
content_type), http_download(url, path) through libcurl (ContentDB,
[CONTENTDB]); send_mail and mail_supported (TLS unless the relay is on this
machine). Given a `redirect` string, http_get and http_post do not follow
a redirect but put its target there and answer "", for a caller that asks
the user about every host; otherwise up to 8 are followed. http_post's
ipv4 sends over IPv4 alone (the Starport announce with no address named,
[DUAL_STACK]).
interface/aitta.h -- interface::aitta ([AITTA_MVP], doc/aitta.txt): an app
as a signed package. keygen, public_of, sign, verify, verify_hash (ECDSA
P-256 through Mbed TLS, deterministic), check_manifest, pack(app_dir,
key_path, out_dir) -> the release .zip beside its .sig, install(zip, sig,
user_path) -> <user>/installed/<author>/<name>/<version>/ after the hash,
signature, manifest and ENGINE_API are checked; a later version under
another key than the first install's is refused.
interface/markup.h -- markup::to_html(md): what a user wrote, as HTML for
a page ([HEARTH_MVP]), through the bundled md4c (3rdparty/md4c): CommonMark
with GitHub's tables, strikethrough, task lists and autolinks, and
||spoilers||. Raw HTML is text, a link or image that is not http, https,
mailto or relative is its text alone, and an image is a link, never
loaded, but for the Hearth's own ("/f/<id>...", relative), an <img>.
"#1234" is a link to /t/1234 (class "ref"), "@name" one to /u/name.
interface/address.h -- host, port and URL parsing in one place
([REWORK_FIXES]): split_host_port(a, &host, &port, def) takes "host",
"host:port", "[v6]", "[v6]:port" and a bare v6 (no port), def when there
is no port, false for an empty host, an unclosed bracket or a port not 1
to 65535; join_host_port(host, port) brackets a v6 host; parse_url(u,
&Url, def_port) splits "scheme://hostport[/path]" into Url {scheme (lower
case), host, port, path, port_given}, http and ws defaulting to 80, https
and wss to 443. util/address_check.sh.
interface/web_brand.h -- web_brand ([HTML_BRAND]): Buildat's look on the
HTML an app serves (Hearth's pages, the Starport's): css, logo (an <img>
of /brand/logo.png); html(s), text escaped for HTML and attributes;
cut(s, n) at a UTF-8 character's start with "..."; page(title, name,
content), a read-only page with the header and the link into the web
client ([FRONT_PAGES]; content already escaped); file(share_path, name,
&data, &type), what /brand/<name> serves (overpass.ttf,
overpass_mono.ttf, logo.png from the share's client/data), so a page
loads nothing from another origin.
interface/zip.h -- zip_list(path) -> ZipEntry list, zip_extract(path, dir).
interface/noise.h -- interface::noise, value noise for an app's generator,
header only: value2/value3 (-1..1, a lattice point every 1), fbm2/fbm3
(octaves of twice the frequency and persist the amplitude, scaled back to
-1..1) and the ridged fbm2_abs/fbm3_abs (0..1), all with uint32_t seeds;
lattice(x, y, z, seed), the hash under them. NoiseParams {offset, scale,
spread_x, spread_y, spread_z, octaves, persist} (a brace list) with
noise2(params, seed, x, z) / noise3(...) in world units, and fill2 /
fill3 writing a region, a sample every 1, x fastest, into a caller's
std::vector<float>. No random number source: std::mt19937 or the app's
own. A Luanti game's noise is Luanti's, luanti_mapgen's NoiseQuery.

Voxels
------

interface/voxel.h -- the voxel data model. VoxelDefinition (name: a
VoxelName of block name and segment; textures, six AtlasSegmentDefinitions;
edge_material_id, face_draw_type, physically_solid, the shape's VoxelQuads,
tile_turns, variants (VoxelVariant: what a param does), tint_ramp,
sag_extent, collision_boxes: what stops the player in a solid voxel that
is not the whole cube, a variant's turned with it, [VL_STAIRS]), VoxelRegistry (createVoxelRegistry(): add_voxel, get_by_id /
get_by_name, get_all, get_count; set_format / get_format; set_look_selector
/ get_look_selector; serialize, and a cache of CachedVoxelDefinition per
id), VoxelFormat (the planes and the roles: VoxelField {plane, shift,
width} for id, light_sky, light_lamp, param, color and the modifiers;
plane_bits, plane_count, plane_of_name, id_of, light_pair,
surface_modifiers, validate; the layouts below and preset(name)),
VoxelSample. voxel_format_self_test(). The Lua side of the same is in
doc/client_api.txt under "Miscellaneous".

**Air says it is air** ([API_DEFAULTS_07]): add_voxel() refuses a
definition with empty edges and nothing of its own to draw (no shape, faces
not ALWAYS) that says neither fully_empty (nothing occupies it: the sky
passes it, a merge writes into it) nor transmits_light (something the sky is
seen through). That was 0.6's air, which stopped the sky at its first voxel.

**A world's voxel format, picked** ([VOXELFORMAT_PRESETS]). There is no
default: a registry's add_voxel() throws until set_format() has been given
a format, so a world that says nothing does not start. A new game picks one
of these, or cuts its own (VoxelFormat, interface/voxel.h):

  blocks()             id 16, light_sky 4, param 8      a block game
  many_ids()           id 21, light_sky 4               many types, no state
  painted()            color 24, light_sky 4, id 4      a colour per voxel
  surfaces()           id 8, light_sky 4, tint, wetness, gloss, sag_top 4
                                                        materials drawn with
                                                        the surface modifiers
  luanti()             id 16, light_sky 4, light_lamp 4, param 8
                                                        Luanti's own
  buildat_legacy_06()  id 21, light_sky 4 (24..27), light_lamp 4 (28..31)
                                                        the cut 0.6 had: the
                                                        compatibility layout

None of the first four binds light_lamp: stored lamp light is a Luanti-ism,
sky light is enough for room and cave light, and a lamp is a light source
at render time. The bits a layout leaves unbound (each one's comment in
voxel.h names them) are the game's: bound to a field of its own in a copy of
the layout before set_format(), not grown into later. VoxelInstance's
legacy06_id(), legacy06_skylight() and legacy06_lamplight() are
buildat_legacy_06()'s bits by hand, right only for a world that set it
(use the buildat_legacy_06() format's id_of() / light_pair() instead).

**A saved world opened under another format** (voxelworld; the rule is
world_persistence_plan.md's "The format, and migration"). The engine moves
data and never reinterprets it:

  same role, same width, another position      moved
  a role or plane the world has, the save not  zero
  a role or plane the save has, the world not  dropped, with a warning
  the id                                       remapped by name (the save's
                                               name table)
  any width change, of a role or named plane   the game's migration, or the
                                               save is refused

The last row because 4 bits into 3 loses data and even 4 into 5 is a
choice -- scale, or zero-extend? -- that only the game can make. The game's
migration is an interface::VoxelMigration (interface/voxel_volume.h) given to
voxelworld's set_migration() before set_save(): per chunk, begin(from, to)
(false declines, and the save is refused) and migrate(old, moved), handed
the chunk as saved and the engine-moved one with the changed fields at zero
to fill. A refused save is neither read nor written further.

interface/voxel_selector.h -- VoxelSelector: the look rules for a world
whose voxels have no id (VoxelRule of VoxelRuleClauses over fields;
fallback), id_of(sample), validate; voxel_selector_self_test().

interface/voxel_volume.h -- interface::VoxelVolume: a chunk's voxels a
plane at a time. getVoxelAt / setVoxelAt on the first plane, plane_at /
set_plane_at and sample_at / set_sample_at for the rest, add_planes,
fill, copy_run_from, the raw bytes (plane_bytes, plane_bytes_for_write,
set_plane_bytes, plane_is_materialised, read_words), getEnclosingRegion,
voxel_count, a PolyVox-style Sampler. serialize_volume / deserialize_volume
in voxel_cereal.h.

interface/voxel_path.h -- interface::voxel_path: A* for a walking body over a
box of cells the caller fills (Field: OPEN, SOLID, CLIMB; outside is
SOLID). Rules: body_height, step_up, max_fall, max_length (voxels walked),
max_expanded. stands, settle (to where a body comes to stand), find (a
Result: found, capped, length, expanded, path), self_test. Walks to the
eight neighbours without cutting corners, steps up, falls, climbs.
util/voxel_path_test.cpp is its check and its timing ([SKELDAT]).

interface/voxel_cereal.h, interface/atlas_cereal.h,
interface/polyvox_cereal.h, interface/urho3d_cereal.h -- cereal
serialization of the voxel types, the atlas definitions, PolyVox regions and
vectors, and Urho3D's vectors, so they cross the wire and the store as one
format.

interface/record.h -- the record rule ([COMPAT_BREAK_07];
doc/architecture.txt): Record<Archive>(archive, what, major, minor) writes
the major and minor, then the fields given to r.ar as one byte string, and
r.end() closes it. Reading, r.minor is the minor written: a newer one's tail
is skipped, another major throws RecordError rather than reading from the
wrong offset. Every cereal type that crosses the wire or the store is one.

interface/protocol.h -- the wire's own records: PROTOCOL_MIN/PROTOCOL_MAX
(one number per minor release) and protocol_features(); Hello (the
core:hello each end sends first: the protocol range, the version, the
engine API, the features), hello_data / hello_of; FileHash and FileContent,
the file transfer's (core:announce_files, core:request_files,
core:file_contents), the server's after a PACKET_PLAIN or PACKET_ZSTD byte.

interface/voxel_cereal_legacy.h -- legacy06::read for what 0.6 wrote, read
only: a saved world's voxel registry (format 2), name table and format
table. 0.7 reads them once and writes the save again in records; it goes at
the next compatibility break.
interface/polyvox_numeric.h -- container_coord / container_coord16: which
chunk a voxel is in.
interface/polyvox_std.h -- dump() and operator<< for PolyVox vectors and
regions, for a log line.

interface/atlas.h -- AtlasRegistry (createAtlasRegistry()): textures packed
into atlases per size; add_segment / find_or_add_segment
(AtlasSegmentDefinition: resource_name, total_segments, select_segment) ->
AtlasSegmentReference, get_atlas_cache / get_texture, set_surface_maps(bool) (the normal and
surface maps beside the diffuse, or not), describe_segments, update().

interface/mesh.h -- the mesher, in the client's process but declared here:
generate_voxel_geometry(result, volume, voxel_reg, atlas_reg,
use_skylight, translucent_result, masked_result, horizon) makes
TemporaryGeometry per atlas, set_voxel_geometry puts it on an Urho3D
CustomGeometry; the LOD pair (generate_voxel_lod_volume /

builtin, the modules' interfaces
================================

builtin/loader/api.h -- loader::Interface: activate(), get_module_info(name).
The first module; it reads meta.json files, resolves the order and loads
the rest; on -R it reloads a module whose sources changed. An app whose
own meta.json has "base" is a variant of that app: the base's modules
load as the variant's own, a module directory in both with a meta.json
in the variant's is the variant's, and one without it overrides only the
client_lua files it has (the order variant, base, builtin, per file).
The variant is its own app everywhere else (its tile, its saves). A
plain name is looked for beside the variant, then in the shipped apps;
"<author>.<name>" among the installed packages (interface::aitta::
find_base; doc/luanti_apps.txt). apps/sample_vanilla_falling_blocks is one.

builtin/main_context/api.h -- main_context::Interface: the server-side
Magic context and its scenes. get_context(), create_scene() ->
SceneReference (an opaque pointer every scene-taking module uses),
find_scene(name), check_scene, delete_scene (SceneDeleted event),
sub_magic_event(scene, event, ...) for a scene's Magic events.

builtin/network/api.h -- network::Interface: send(peer, name, data),
list_peers(), set_send_policy(policy, max_queue_bytes, grace_us) --
SendPolicy Buffer (queue without bound), Drop (a new packet over the limit
is dropped), Disconnect (over the limit for grace_us and the peer is let
go; the default, at 8 MB and 30 s [API_DEFAULTS_07]); the grace counts from
when the socket last took anything from the peer. declare(name, Channel::LatestOnly): a packet
of that name waits in a lane of its own where a newer one replaces an
older still queued (positions, HUD values) and goes ahead of the ordered
queue -- except a peer's first packets of the name, which go ordered
behind what was queued before them, so a payload cannot overtake its own
definition or the modules that subscribe to it. A payload over 64 KB is
fragmented on the wire and handed back whole. disconnect(peer) lets it go
once its queue has gone (two seconds at most). The HTTP face on the same
port: a request under /api/, or under a prefix the module claimed with
claim_http_path(prefix) ([HEARTH_MVP]: Hearth's pages), comes as
"network:http_request" (HttpRequest: peer, method, path, query, body of 64
KiB at most, address) and is answered with http_respond(peer, status,
content_type, body); HttpRequest::param(key) and query_value(query, key)
read a query's value, '+' and %XX decoded. serve_brand(server, r)
answers /brand/<name> (web_brand.h's fonts and logo). RateTable
([SHARED_HELPERS], Starport's, Aitta's and Hearth's): ok(what, who, max,
per) says whether one more fits in per seconds, bounded (a long key
hashed, passed windows swept, a new key refused past a ceiling). The
web client's files are never claimed: it is at
/play and /app ([PLAY_PATH]: a link picks by the listing's kind, world
or arena -> /play), /index.html, and / unless "/" is claimed. /health
(JSON: app, version, uptime_s, players, tick_gap_ms_avg and _max over
the last minute -- 33 ms is on time --, memory_bytes) and /metrics (the
same in Prometheus' text format) are a monitor's ([SERVER_HEALTH]):
open from this machine, unless the request carries X-Forwarded-For,
Forwarded or X-Real-IP (a proxy), and from elsewhere with the token in
<user>/apps/<app>/health_token.txt, made at the first start, as
"Authorization: Bearer <token>" or ?token=<token>. health_json() is
the same JSON for a module. listen_on(address) listens on another address too, on
the same port (a launcher's 127.0.0.1 game opened to the LAN);
lan_announce(name, account) says every 2 s on the LAN group that this
server is here, "" stops ([LAN_DISCOVERY]). Events:
"network:client_connected" (NewClient), "network:client_disconnected"
(OldClient), "network:packet_received/<name>" (Packet: sender, name,
data); a packet no module subscribed to is dropped. PeerInfo (id, address,
web: came through a WebSocket, which any page the user visits can open to
127.0.0.1) and PeerId.

**The server's icon** ([FAVICON_SERVER_ICON]): the admin puts a PNG of
64 KB at most at <user>/apps/<app>/server_icon.png (the -D directory's
apps/<app>/, beside the app's save), and it is read at server start. It
is the server's icon in the client's list of servers (sent as
core:server_icon on connect; without it, the first picture in the app's
launcher/) and its /favicon.ico in a browser tab (without it, what the
app set with set_favicon, else the Buildat logo). A file that is not
such a PNG is skipped with a warning in the log. As the server's icon it
is 64 pixels a side at most: a larger one is scaled down where the
server has main_context, else skipped. starport_announce sends it with
each announce, so a Starport's listing carries it ([SERVER_ICONS]).

What the module enforces on its own ([SECURITY_RUN_1], [PEER_TIMEOUT]):
32 connections from one address at most, peers capped under what select()
can watch, a peer's socket not read while 100 of its packets wait, a peer
silent for 60 s dropped (it sends network:keepalive to a game peer it has
sent nothing for 5 s, and the client does the same), the local pipe taking
no remote client, and a POST's Content-Length of nine digits at most.

builtin/client_file/api.h -- client_file::Interface: add_file_content(name,
content) and add_file_path(name, path) put a file in the namespace the
client mirrors into its cache by hash; FilesTransmitted says a peer has
them all. builtin/client_lua and builtin/client_data are built on it.

builtin/replicate/api.h -- replicate::Interface: a scene mirrored to peers.
assign_scene_to_peer(scene, peer), find_peers_on_scene,

PeerJoinedScene / PeerLeftScene.

builtin/accounts/api.h -- accounts::Interface: who may join and as whom,
for every app on the server. name_of(peer), find_peer(name) (the first
connection) and find_peers(name) (all of them), address_of, is_admin,
exists, account_names, is_local (the launcher's own user of a server it
started -- told by the token the launcher gives its server in
BUILDAT_OWNER_TOKEN and its own client, never a WebSocket peer), launched;
kick, ban(name, by, until, reason) (by name, and by address while
registration is open; until 0 or a time it lifts itself at, and the
reason, both said at a refused join),
unban(name_or_address, only_by) (with only_by, only that one's bans: a
game's /unban lifts the game's), ban_list; create_account, check_password,
set_password, delete_account; TOTP (totp_on, check_totp, totp_begin,
totp_confirm, totp_off, totp_uri); reported_bans, registration_open,
linked_count (the Starport's side, 10d and 10g). level(name) and
set_level(name, lv, by) ([TRUST_LADDER]): an account's trust level, a
number saved with it (LV_NEW 0, LV_MEMBER 10, LV_HELPER 20,
LV_MODERATOR 30; the admin is LV_ADMIN 40), named by level_name() (Guest,
Resident, Keeper, Steward, Host); accounts::level(server, name) is the
same from another module, for an app's admin and moderator tests. LV_MEMBER and up is trusted: open
registration takes at most 5 untrusted accounts made in 30 days from one
network, address_bin(), and 50 a day in all. With `by`, one sets only
below one's own level, from LV_MODERATOR; a moderator has the Server
window's Accounts page but for passwords, deletion, adding and the
settings. A kept login lasts 90 days from its last use. set_multiple_logins(on):
whether one name may be here from several clients at once
([FP_TWO_CLIENTS]; off by default, floorplanner turns it on), and then a
kick, a ban, a password an admin resets and a deleted account reach every
connection of it. set_guests(on): a "Play as a guest" button on the login
window, joining as "guest<n>" with no account, trust level 0
([HC_GUEST_PLAY]; off by default, hillclimb turns it on). Events: accounts:login (Login: peer, name),
accounts:privs. can_mail / mail(to, subject, text, done) send through
the server's SMTP server, which the admin sets on the Server window's
Health page (kept in the accounts store; the password never goes back
to a client).

The Server window (builtin/accounts' client Lua, [SERVER_ADMIN_PAGE]):
a sidebar of pages, Account; for an admin Accounts, the Starport pages
(when starport_announce is loaded), Statistics and Health (disk, the server's sandbox and a
check of it, the last 100 warnings and errors, mail, the listings); for a
moderator Accounts and Statistics. **Statistics** ([SERVER_STATS]): accounts
samples the players joined, the peak tick gap and the memory each minute
into a row an hour (stats/h/, kept eight days; joins, distinct names and
accounts made counted in it too), folded into a row a day when the day ends
(stats/d/, kept for ever), and per account the last join and the time joined
(seen/<name>); the page draws the week by the hour and the half year by the
day as bar graphs (the players' most, average and fewest), the line under
them the bar the pointer is on, and the accounts by level, made in 30 days,
not joined in 90 and the ten with the most time joined. The
"Server" corner button and a game's My account open it as a window of
its own, closed by Close or a click outside it. An app adds its
own pages with accounts.server_menu = function(add) add(header, label,
key, draw, count) end, and may make the window its own UI with
accounts.server_window(key) and server_open(title) (Starport, Aitta);
server_window(key, nil, accounts.ask_exit) gives it a × asking "Exit to
launcher?", passed where accounts.can_exit() ([STARPORT_CLOSE]);
accounts.health_rows(w) adds rows to Health.
